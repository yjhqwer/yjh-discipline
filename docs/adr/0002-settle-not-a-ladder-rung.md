# Settle is a verdict bar, not a fifth ladder rung

The search-before-settling rule requires "keep the status quo" to be justified like any other outcome. We could have made Settle the fifth rung of the Adopt→Extend→Compose→Build ladder; instead the ladder stays four-rung, and Settle lives as an evidence bar in the rules plus a verdict form in the prior-art-search output section. Rationale: the ladder answers "what do we adopt", and Settle is not an adoption target — it is the outcome when research shows the current state already wins. Every existing reference to the four-rung ladder (both READMEs, the rules template, the skill) would need touching for a change that adds no routing power.
