# j-space

Original skill by **yjh** (this repository's author).

The premise is grounded in Anthropic's interpretability research:
[**"Verbalizable Representations Form a Global Workspace in Language Models"**](https://transformer-circuits.pub/2026/workspace/index.html)
(Gurnee, Sofroniew, Lindsey et al., Transformer Circuits, July 2026) — the paper that identified
the internal workspace it names **J-space**. What is built on that finding here — the passes,
the ledger, the modules, the controller — is the author's own work.
