# j-space

This folder is a **locally modified copy** of the [**J-Space Cognition Suite**](https://github.com/Tiger3807861189/J-Space-Cognition-Suite)
by **Tiger3807861189** (≈3k stars on GitHub).

- **License: Apache-2.0.** `LICENSE` and `THIRD_PARTY_NOTICES.md` in this folder are included
  as the upstream distribution requires. They take precedence over this repository's MIT
  license **for this folder only**.
- **What was changed locally:** the entry file (`SKILL.md`) was restructured and the suite
  trimmed to a leaner 9-module / 4-reference layout; this copy corresponds to an earlier
  point of the upstream line, with additional local edits. The premise and large portions of
  the module text remain verbatim from the upstream suite.
- **Research basis:** Anthropic's interpretability research
  [*"Verbalizable Representations Form a Global Workspace in Language Models"*](https://transformer-circuits.pub/2026/workspace/index.html)
  (Gurnee et al., July 2026) — the paper that identified and named the model's internal
  workspace **J-space**. All credit for the methodology belongs to the upstream author.
